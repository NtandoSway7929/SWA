Questions, answered

Before you get started.

Do I need a domain name first?

A branded email address normally requires a domain. If you do not have one, we can discuss the domain options and associated costs separately.

Does the price include a mailbox subscription?

No. Provider subscriptions, domain registration and third-party charges are separate unless included in a written quote.

Can you set up more than one mailbox?

The number of mailboxes and configuration requirements affect the scope. Tell us how many addresses you need.

Will it work on my phone?

We can guide you through accessing the configured mailbox using the agreed email app and provider.

Is an email signature included?

A professional signature is part of the listed service scope. We will agree the details and format before creating it.

Can you guarantee every email reaches the inbox?

No. Delivery depends on provider configuration, recipient systems and sender reputation. We can check the agreed setup but cannot guarantee inbox placement.
