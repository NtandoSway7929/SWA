# Hallmark for SWA (explicit opt-in)

This skill is not a default design workflow. Use it only when the user explicitly names Hallmark or asks for a Hallmark design, audit or redesign. A general request to design, build, improve or art-direct a site does not activate it.

Before applying upstream guidance, read SWAYPHICS-ADAPTATION.md, then UPSTREAM-SKILL.md. The local adaptation and repository instructions take precedence over the upstream file wherever they differ.

The original upstream prompt is retained in UPSTREAM-SKILL.md; its linked reference playbooks, theme catalogue, sample fixtures and selected utility scripts are stored alongside it. See the adaptation file for the deliberately excluded installers, hooks, API-backed features and browser-rendering utilities.
