# Swayphics adaptation

Ponytail is an implementation-discipline skill, not permission to reduce the user's requested scope.

- The request and acceptance criteria define the complete task. "Smallest complete change" means no unnecessary extras, not an incomplete solution.
- Existing repository architecture, Vanilla HTML/CSS/JavaScript constraints, security, validation, accessibility, test and documentation requirements take precedence.
- Do not add frameworks, packages, services, APIs, hooks or runtime tooling without explicit approval.
- Do not edit protected production, admin, client-portal, deployment or Supabase areas without explicit approval.
- Inspect callers, dependencies and current behavior before changing shared code. Keep safeguards and error handling.
- Never claim a command, test, browser check or deployment passed unless it actually ran and passed.
- Apply this guidance to coding work only. Do not treat Ponytail's upstream session toggle as a global instruction for unrelated tasks.
