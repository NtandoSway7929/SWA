# Ponytail for SWA

Apply Ponytail to coding work in this repository. Read the local SWAYPHICS-ADAPTATION.md before applying the upstream guidance in UPSTREAM-SKILL.md.

Use the smallest complete change that satisfies the user's actual request. Do not use minimalism as a reason to omit requested functionality, required validation, error handling, security, accessibility, regression tests or necessary documentation.

This skill does not authorise production changes, new dependencies, destructive data operations, deployments or external actions. Follow repository and project approval boundaries first.
